# Roadmap

## v0.1.0 — Last Light

- [x] AC-130 → artillery → M2 station rotation.
- [x] Three gunship weapons, delayed explosive shells, M2 heat and ammunition.
- [x] Escalating seeded hordes, three enemy classes and three difficulties.
- [x] Three-card upgrade drafts with persistent station ranks.
- [x] Procedural pixel/voxel views, soundtrack and sound effects.
- [x] Mouse, keyboard, touch and standard gamepad input paths.
- [x] Offline cache, provenance verification and browser/CI checks.

## v0.2.0 — Fire in the valley

- [x] Outruin-style Fit window / Fullscreen / Windowed page controller.
- [x] Whole-game fit at desktop, short laptop, portrait and landscape touch sizes.
- [x] VANILLAJS ballistic shell/debris motion and building collision.
- [x] Horde steering, blast knockback, direct-fire headshots and fuel chains.
- [x] Articulated characters, richer terrain, persistent impact marks and layered explosions.
- [x] Station-specific soundtracks, layered spatial FX and three WAV exports.
- [x] Seeded physics/audio checks and browser fullscreen/layout/visual evidence.

## Gunship and march update

- [x] 40 mm inherits the previous 105 mm damage and splash radius.
- [x] 105 mm gains a much wider damage footprint, larger explosion, more debris and a heavier report.
- [x] Projected landing/blast guides agree with world-space damage range.
- [x] Original deterministic Last Light March with three arrangements and full WAV export.
- [x] AC-47 namesake story, original README banner and soundtrack preview.

## Long watch — fourth station

- [x] AC-130 → artillery → M2 → fixed 20 mm sniper rifle rotation.
- [x] QUICKSCOPER-derived scope settle, one-click trigger and short bolt buffer.
- [x] Shared rendered head/body hitboxes and wall-blocked, attenuated collaterals.
- [x] Quickscope/headshot bonuses, collateral feedback and dedicated station upgrades.
- [x] Mouse, keyboard, touch and standard-gamepad scoping; focus/disconnect cancellation.
- [x] Original Canvas rifle/bolt/scope visuals, rifle report, chambering sound and Long watch march.
- [x] Four-station README banner, field manual and source adaptation record.

## Possible next operations — not implemented

- Data-only mod packs and an in-game operation/upgrade editor.
- More outpost layouts, destructible buildings and boss waves.
- Replay export/import with explicit versioned command records.
- Controller calibration and physical-device compatibility evidence.
- Longer compositions and adaptive musical intensity layers.
- Additional aircraft and infantry weapons with distinct upgrade branches.

Balance changes should follow actual play reports, with seed, difficulty and round attached when possible.
